# InquiryListPage.tsx に関する疑問と回答メモ

### Q1. `type FilterValue = InquiryStatus | "all";` と `type SortValue = "date" | "status";` は何？
**A.** この画面内だけで使用する**「状態（State）の限定ルール（型）」**を定義している。
* `FilterValue` ➔ 絞り込みボタンの状態は、既存のステータス（`pending`等）に加えて、すべてを意味する `"all"` のいずれかしか受け付けないという制限。
* `SortValue` ➔ 並び替えの状態は、日付順を意味する `"date"` か、ステータス順を意味する `"status"` のどちらか2択であるという制限。

---

### Q2. `const [filter, setFilter] = useState<FilterValue>("all");` 周りの状態管理の意図は？
**A.** **「現在、ユーザーがどの絞り込みボタン（すべて、未対応など）と、どの並び替えボタン（日付、ステータス）を選択しているか」を記憶・管理する領域**である。
初期値として、絞り込みは `"all"`（すべて）、並び替えは `"date"`（日付順）がセットされる。ユーザーがボタンをクリックすると、`setFilter` や `setSortBy` が走り、画面が瞬時に再描画（レンダリング）される。

---

### Q3. `const countAll = inquiries.length;` などの4行の処理は何をしている？
**A.** **現在保持している全宇宙ログの中から、各ステータスに該当する件数をリアルタイムに合算・計算している。**
* `inquiries.length` ➔ 全体の総件数。
* `.filter((i) => i.status === "pending").length` ➔ 配列内を走査し、ステータスが `pending` のデータだけの個数を数え上げる。
ここで計算された数値が、ボタンの横の `すべて (3)` や `未対応 (1)` というバッジ件数表示にダイレクトに反映される。

---

### Q4. `const filteredInquiries = ...` は何をしている？
**A.** **Q2で記憶した `filter` の状態を見て、表示すべきデータだけにリストを削ぎ落とす「第1段階のデータ加工（絞り込み）」である。**
* 現在の状態が `"all"` の場合 ➔ 親から受け取った `inquiries`（全データ）をそのままスルーパスする。
* それ以外（`pending`等）の場合 ➔ ログのステータスが、選択中のフィルター文字列と完全一致するものだけを `.filter` で抽出する。

---

### Q5. `const sortedInquiries = [...filteredInquiries].sort(...)` の並び替えの仕組みは？
**A.** **Q4で絞り込んだデータに対して、ユーザーが望む順番へ並び替える「第2段階のデータ加工（ソート）」である。**
* `[...filteredInquiries]` ➔ JavaScriptの `sort` 関数は元の配列を直接書き換えてしまう（破壊的変更）特性があるため、スプレッド構文（`...`）を使って一度安全にコピーを作成している。
* `sortBy === "date"`（日付順） ➔ データの未来・過去をミリ秒単位の数字（`.getTime()`）に変換し、新しい日付が上（降順）になるように引き算を行う。
* `else`（ステータス順） ➔ `pending` を1番、`in_progress` を2番、`completed` を3番とする優先度マップ（`priority`）を定義し、未対応のログが最優先で上に並ぶようにソートする。

---

### Q6. `const getButtonClass` と `getSortButtonStyle` の役割は？
**A.** **「現在選択されているアクティブなボタン」の背景色や見た目を変化させ、ユーザーに現在の制御状態を直感的に伝えるための動的スタイリング関数**である。
* `filter === targetFilter` または `sortBy === targetSort` という条件式を用いて、現在アクティブなボタンであると判定された場合のみ、キャプテンEOを象徴する紫（`#7a3bf5`）やピンク（`#da70d6`）の背景色オブジェクトを返却し、HTMLに適用させている。

---

### Q7. `{filteredInquiries.length === 0 ? ( ... ) : ( <InquiryTable ... /> )}` は何をしている？
**A.** **絞り込みの結果、表示すべきログが1件も存在しない場合の画面の「出し分け（条件付きレンダリング）」を行っている。**
* 件数が 0 件の場合 ➔ 「該当する問い合わせはありません。」または「No transmissions found in this sector.」という、中央制御室にログがない旨の警告テキストを表示する。
* 1件以上存在する場合 ➔ Q5で「絞り込み」と「並び替え」を完全に完了させた最高純度のデータ（`sortedInquiries`）を、下位コンポーネントである `<InquiryTable />` へ Props として引き渡し、綺麗な表として描画させる。
