# InquiryTable.tsx に関する疑問と回答メモ

### Q1. `import type ...` や `import { InquiryRow } ...` は使うパーツを持ってきているってこと？
**A.** **大正解です！**
プログラミングの世界ではこれを「インポート（輸入）」と呼びます。
* `Inquiry`: データの設計図（型）を持ってきています。
* `InquiryRow`: テーブルの「1行分を表示するボタン付きのパーツ」を持ってきています。
このように、別ファイルで定義したパーツを呼び出して合体させるために書きます。

---

### Q2. `=> void` （ボイド）って何？
**A.** **「この関数は、処理を実行するだけで、何も値を送り返しません」という宣言**です。
`void` は英語で「空っぽ」「無」という意味。例えば、「詳細画面を開く」「データを消す」という処理は、ボタンを押した瞬間に実行されればそれで終わりで、その後に何か別のデータ（計算結果など）を受け取る必要がないため、`void`（ボイド）型に指定します。

---

### Q3. `export const`（コンスト）って何？
**A.** **「一度決めたら中身が変わらない変数（定数：constant）を作って、外に公開（export）する」**という意味です。
Reactのコンポーネント（UI部品）は、プログラム上では「1つの大きな関数（処理の塊）」として作られます。そのため、「`InquiryTable` という名前の変更されない関数（パーツ）を作って、他のファイルからも使えるように公開するよ！」という合図になります。

---

### Q4. `({ inquiries, onSelect, onDelete, lang }: InquiryTableProps) => {` この辺はデータの要素を書いているのかな？
**A.** **その通り、親（Page）から送られてきた「仕送り箱の中身（要素）」をここで受け取っています！**
この `InquiryTable` というパーツが正しく動くために必要なものの一覧（宇宙ログのリスト、クリック時の関数、現在の言語）を、右側の `InquiryTableProps`（取扱説明書）のルールに従って開封し、関数の中で使えるように準備している場所です。

---

### Q5. `const labels = lang === "ja" ...` ここで日本語の場合の処理ね？
**A.** **その通りです！**
「もし `lang` が `ja`（日本語）なら、テーブルのヘッダー（見出し）に使う言葉を『タイトル』や『ステータス』にするよ」という設定をしています。

---

### Q6. `: { ... }` の部分は、日本語とそれ以外（英語）ってことね？
**A.** **大正解、お見事です！**
今回は `ja` か `en` の2種類しかありませんが、このコロン（`:`）は「そうじゃなければ（英語なら）」を意味します。ここで `SUBJECT` や `STATUS` といった、英語モード用の見出し文字列をセットしています。

---

### Q7. `<thead> <tr> <th>...` ここは何を出力するかの場所だね
**A.** **その通り！テーブルの「一番上のヘッダー（見出し行）」を出力する場所です。**
* `<thead>`: テーブルの頭（Header）という意味のグループ。
* `<tr>`: テーブルの「行（Row）」を作るタグ。
* `<th>`: ヘッダー用の「太字の見出しセル（Header Cell）」を作るタグ。
ここで、先ほど Q5・Q6 で言語ごとに切り替えた `{labels.title}` などの文字を流し込み、表の1番上のタイトル行をカチッと作っています。

---

### Q8. `<tbody>` の中身（`inquiries.map` 周り）は何をしているの？
**A.** **「親から届いた宇宙ログのリスト（配列）を上から1件ずつ取り出して、全員分の行パーツ（`InquiryRow`）を自動で並べるループ処理」をしています！**
Reactで最も重要な超頻出コードです。

* `<tbody>`: テーブルの「データ本体（Body）」を入れるグループ。
* `inquiries.map(...)`: `inquiries`（ログの配列）の中身を上から順にループでスキャンしています。
* `<InquiryRow ... />`: スキャンしたログを1件ずつこの行パーツに流し込み、データの数だけ自動で `<tr>`（行）を画面にレンダリング（描画）しています。
* `key={inquiry.id}`: Reactが「何件目のデータを書き換えたか」を正しく見失わないようにするための、宇宙で1つだけの識別番号（ID）です。
